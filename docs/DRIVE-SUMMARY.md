## Reglas ("Connect AI Build — Reglas del Juego")
- Un día, un reto, equipos de **1–3 personas** (el acuerdo dice "hasta 3").
- Entregable: **prototipo o demo + pitch de 3 min + explicación rápida de cómo se usaría de verdad**.
- **Código durante el evento:** "No llegues con el proyecto ya hecho. Ideas, research o exploración previa de las APIs sí; producto armado, no." El acuerdo dice: "El trabajo presentado debe desarrollarse durante el hackathon… no presentar un producto previamente construido como si se hubiera creado en el evento."
- Transparencia: hay que declarar el código propio, las librerías, la IA generativa, los datos y los recursos de terceros. "Nadie te va a penalizar por usar herramientas, sí por esconderlo."
- No copiar trabajo ajeno. Hay que tener derecho a usar los datasets, el código y los assets que lleves.
- No abusar de las APIs/sandboxes; son solo para el evento.
- Si incumples, puedes quedar fuera de premios o ser descalificado.
- El evento no responde si pierdes código o si se cae una API.
- Habrá fotos y video; avisa si no quieres salir.
