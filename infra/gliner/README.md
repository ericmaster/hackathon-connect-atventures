# gliner — intent + entity layer (feasibility)
What: `fastino/GLiNER2.5-multi-Decide` @ `a35a0cd` (Apache-2.0, multilingual, 287M params, 1.15 GB fp32) via `gliner2[local]==2.0.0`. Per utterance: 2 calls: `classify_text` (intent; labels = short EN phrases mapped back to ids, descriptions hurt) + `extract_entities` (sintoma/cedula/ubicacion/producto with descriptions, threshold 0.15; entity scores run 0.2–0.5, so ≥0.3 drops them). Defaults in `app.py`.
Local: `python -m venv .venv-gliner && .venv-gliner/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu "gliner2[local]==2.0.0" protobuf` → `.venv-gliner/bin/python infra/gliner/app.py "quiero pagar"`.
Deploy (no local docker): `upload-weights.sh` pins weights in private `s3://connect-atv-gliner-build-325556500173/models/...`; zip `Dockerfile app.py buildspec.yml` → `s3://…/gliner-src.zip` → CodeBuild `connect-atv-gliner-build` → ECR `connect-atv-gliner:v3` (code only, 0.5 GB) → Lambda `connect-atv-gliner` (6144 MB, 300s, /tmp 2048 MB, env MODEL_S3, no URL). Weights live in S3 because Lambda's lazy image loading of a baked weights layer was too slow (>300s). us-east-1, tag `project=connect-atventures`.
Invoke: `aws lambda invoke --region us-east-1 --function-name connect-atv-gliner --cli-binary-format raw-in-base64-out --payload '{"texts":["quiero pagar"]}' out.json`. Overrides: `intents` (list of ids or {id: label_text}), `entities` (list or {name: desc}), `threshold` (entities).
Perf: cold ~30s (13s S3 fetch + ~15s load; first after deploy ~86s), warm ~0.44s/utt (~1.5s wall incl. CLI). Use `AWS_MAX_ATTEMPTS=1 --cli-read-timeout 300` on cold calls or the CLI retries into parallel sandboxes.
Teardown (`--region us-east-1`): `aws lambda delete-function --function-name connect-atv-gliner; aws ecr delete-repository --repository-name connect-atv-gliner --force; aws codebuild delete-project --name connect-atv-gliner-build; aws s3 rb s3://connect-atv-gliner-build-325556500173 --force; aws iam delete-role-policy --role-name connect-atv-gliner-codebuild --policy-name build; aws iam delete-role --role-name connect-atv-gliner-codebuild; aws iam delete-role-policy --role-name connect-atv-gliner-lambda --policy-name model-read; aws iam detach-role-policy --role-name connect-atv-gliner-lambda --policy-arn arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole; aws iam delete-role --role-name connect-atv-gliner-lambda`.
