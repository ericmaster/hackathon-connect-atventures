# gliner — intent + entity layer (feasibility)
What: `fastino/GLiNER2.5-Decide` (Apache-2.0, DeBERTa-v3-large, ~486M params fp32, 1.95 GB) via `gliner2[local]==2.0.0`. One call = intent (classification) + entities (sintoma/producto/cedula/ubicacion). Labels passed at call time (`app.py`). Model card says English; Spanish works on synthetic tests. Multilingual sibling: `fastino/GLiNER2.5-multi-Decide`.
Local: `python -m venv .venv-gliner && .venv-gliner/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu "gliner2[local]==2.0.0"` → `.venv-gliner/bin/python infra/gliner/app.py "quiero pagar"`.
Deploy (no local docker): zip `Dockerfile app.py buildspec.yml` → `s3://connect-atv-gliner-build-325556500173/gliner-src.zip` → CodeBuild `connect-atv-gliner-build` builds image (weights baked) → ECR `connect-atv-gliner:v1` → Lambda `connect-atv-gliner` (container, 10240 MB, 600s timeout, no URL). us-east-1. Tag `project=connect-atventures`.
Invoke: `aws lambda invoke --region us-east-1 --function-name connect-atv-gliner --cli-binary-format raw-in-base64-out --payload '{"texts":["quiero pagar"]}' /dev/stdout`. Optional keys: `intents` (list or {label: desc}), `entities`, `threshold`.
Cold start 25–160 s (lazy image fetch of 1.95 GB weights; 6144 MB was worse, ~2 s/utt warm). Warm ~0.9–1.7 s/utt in Lambda, ~2 s wall incl. CLI. Load lazy (first invoke). For demo: keep-warm ping or fp16 / multi-Decide (287M).
Teardown: `aws lambda delete-function --function-name connect-atv-gliner; aws ecr delete-repository --repository-name connect-atv-gliner --force; aws codebuild delete-project --name connect-atv-gliner-build; aws s3 rb s3://connect-atv-gliner-build-325556500173 --force; aws iam delete-role-policy --role-name connect-atv-gliner-codebuild --policy-name build; aws iam delete-role --role-name connect-atv-gliner-codebuild; aws iam detach-role-policy --role-name connect-atv-gliner-lambda --policy-arn arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole; aws iam delete-role --role-name connect-atv-gliner-lambda` (all `--region us-east-1`).
